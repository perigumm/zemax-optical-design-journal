# Optical System Design Journal

A continuously developing portfolio of optical system design studies using Ansys Zemax OpticStudio.

## Focus

- Telescope optical systems
- Astronomical instrumentation
- Space-based optical instruments
- Imaging systems
- Spectrometers and monochromators
- Optical optimization and tolerancing

I am using this repository to document my continuous practice in optical system design, record what I learn, and develop practical skills for future work in astronomical and space optical instrumentation.

- Python
- Optical design and analysis methods
